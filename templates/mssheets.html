Unit 4: Spreadsheets

Days 26–35 · Learn to organize data and perform calculations using Microsoft Excel or LibreOffice Calc.

Learning Objective: By the end of this unit you will be able to enter and organize data, use formulas and functions, format cells, and build charts from spreadsheet data.
1. Introduction to Microsoft Excel/LibreOffice Calc

Spreadsheet software is used to store, organize, and calculate data using a grid of rows and columns.

  • Workbook - the entire file
  • Worksheet - a single sheet/tab within the workbook
  • Cell - the intersection of a row and column
2. Rows, Columns, Cells, and Data Entry
  • Rows are numbered (1, 2, 3...) and columns are lettered (A, B, C...)
  • Each cell has an address, e.g. B4
  • Data can be text, numbers, or dates
  • Use Tab and Enter to move between cells while entering data
3. Basic Formulas and Calculations

Formulas always begin with an equals sign (=) and can perform arithmetic on cell values.

FormulaResult
=A1+A2Adds the values in A1 and A2
=A1-A2Subtracts A2 from A1
=A1*A2Multiplies A1 and A2
=A1/A2Divides A1 by A2
4. Functions (SUM, AVERAGE, MAX, MIN)
FunctionPurpose
=SUM(A1:A10)Adds all values in the range
=AVERAGE(A1:A10)Finds the mean value
=MAX(A1:A10)Finds the highest value
=MIN(A1:A10)Finds the lowest value
5. Cell Formatting and Data Organization
  • Number formats - currency, percentage, date
  • Bold, color, and borders for emphasis
  • Column width and row height adjustments
  • Freezing panes to keep headers visible
6. Charts, Sorting, and Filtering
  • Insert charts (bar, line, pie) to visualize data
  • Sort data alphabetically or numerically, ascending or descending
  • Filter data to show only rows matching certain criteria
7. Practical Spreadsheet Project and Quiz
  1. Create a spreadsheet tracking weekly expenses across five categories.
  2. Use SUM to calculate the total for each category and overall total.
  3. Use AVERAGE to find the average daily expense.
  4. Create a pie chart showing the expense breakdown.
  5. Sort the data by highest to lowest expense.
Quick Quiz
  1. What symbol must every formula begin with?
  2. What does the AVERAGE function calculate?
  3. Name one chart type used to visualize data.
  4. What is the difference between sorting and filtering?
