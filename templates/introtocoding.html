Unit 7: Introduction to Coding

Days 46–50 · Learn computational thinking and write your first simple programs.

Learning Objective: By the end of this unit you will understand what algorithms are, think through problems step by step, and build a simple program using Scratch or Python.
1. Introduction to Coding and Computational Thinking

Coding is the process of writing instructions that a computer can follow. Computational thinking is a way of breaking problems into clear, logical steps.

  • Decomposition - breaking a big problem into smaller parts
  • Pattern Recognition - spotting similarities between problems
  • Abstraction - focusing on important details, ignoring the rest
  • Algorithm Design - creating step-by-step solutions
2. Algorithms and Flowcharts

An algorithm is a sequence of steps used to solve a problem or complete a task. Flowcharts use symbols to represent these steps visually.

SymbolMeaning
OvalStart / End
RectangleProcess / Action
DiamondDecision (Yes/No)
ArrowFlow direction
3. Scratch or Python Basics

Scratch uses drag-and-drop visual blocks to build programs, ideal for beginners.

Python uses text-based code and is a popular beginner-friendly programming language.

  • Variables - store data like numbers or text
  • Loops - repeat actions multiple times
  • Conditionals (if/else) - make decisions in code
  • Events - trigger actions (e.g. "when key pressed")
4. Creating Simple Programs and Animations
  • Move a character across the screen using loops
  • Make a sprite respond to key presses or clicks
  • Use conditionals to create simple games, like a quiz or catch-the-object game
5. Mini Coding Project
  1. Plan a simple program idea (e.g. a story, a quiz, or a simple game).
  2. Sketch a basic flowchart of the program's logic.
  3. Build the program in Scratch or Python.
  4. Test the program and fix any errors (debugging).
6. Final Project Showcase and Course Review
  • Present the mini coding project to the class
  • Explain the logic and choices made while building it
  • Reflect on skills learned across all units of the course
