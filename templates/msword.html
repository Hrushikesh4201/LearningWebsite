Unit 3: Word Processing

Days 16–25 · Learn to create clean, professional documents using Microsoft Word or LibreOffice Writer.

Learning Objective: By the end of this unit you will be able to type efficiently, format text and paragraphs, insert images and tables, and produce a professional document from start to finish.
1. Introduction to Microsoft Word/LibreOffice Writer

Word processors are applications used to create, edit, and format text documents such as letters, reports, and resumes.

  • Ribbon/Toolbar - contains formatting commands
  • Document Area - where you type your content
  • Rulers & Margins - control page layout
2. Typing Skills and Keyboard Shortcuts

Good typing habits improve speed and accuracy. Keyboard shortcuts save time on repeated actions.

ShortcutAction
Ctrl+BBold
Ctrl+IItalic
Ctrl+UUnderline
Ctrl+ZUndo
Ctrl+SSave
Ctrl+PPrint
3. Text and Paragraph Formatting
  • Font style, size, and color
  • Text alignment - left, center, right, justify
  • Line spacing and paragraph spacing
  • Indentation for structured writing
4. Bullets, Numbering, and Page Layout
  • Bulleted lists for unordered points
  • Numbered lists for sequential steps
  • Page size, orientation, and margins
  • Headers, footers, and page numbers
5. Inserting Images, Shapes, and Tables
  • Insert → Pictures to add images from a device
  • Insert → Shapes for arrows, boxes, and callouts
  • Insert → Table to organize information in rows and columns
  • Wrap text around images for a polished layout
6. Creating Professional Documents

Professional documents combine formatting, structure, and clarity.

  • Consistent fonts and heading styles
  • Clear title and section headings
  • Proper spacing and alignment
  • Proofreading before finalizing
7. Practical Document Project and Assessment
  1. Create a one-page resume or event flyer.
  2. Include a title, at least one image, and a bulleted list.
  3. Add a table summarizing key information.
  4. Format headings, spacing, and alignment consistently.
  5. Save and submit the final document for review.
