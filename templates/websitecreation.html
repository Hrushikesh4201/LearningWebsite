Unit 6: Website Creation

Days 41–45 · Learn the basics of web design and build a website using the Wix platform.

Learning Objective: By the end of this unit you will understand core web design principles and be able to build, customize, and publish a simple website using Wix.
1. Introduction to Websites and Web Design

A website is a collection of linked pages accessed through a browser, made up of text, images, and interactive elements.

  • Homepage - the main landing page of a site
  • Navigation - menus that let visitors move between pages
  • Layout - how content is arranged on the page
2. Exploring the Wix Platform

Wix is a drag-and-drop website builder that lets you design a site without writing code.

  • Templates - pre-designed starting points for a site
  • Editor - the drag-and-drop workspace
  • Elements Panel - add text, images, buttons, and more
3. Creating and Customizing a Website
  • Choose a template that fits the site's purpose
  • Customize colors, fonts, and layout to match a theme
  • Add or remove pages as needed
  • Preview the site on desktop and mobile views
4. Adding Text, Images, Buttons, and Links
ElementPurpose
Text BoxDisplays headings and paragraphs
ImageDisplays photos or graphics
ButtonTriggers an action, like navigating to a page
LinkConnects to another page or website
5. Website Design Principles and Publishing
  • Keep layouts clean and uncluttered
  • Use consistent colors and fonts throughout the site
  • Ensure text is readable and images are relevant
  • Publish the site to make it live on the web
6. Final Website Presentation
  1. Choose a topic for a personal or hobby website.
  2. Build at least three pages: Home, About, and Contact.
  3. Add text, at least two images, and one button or link.
  4. Publish the site and share the link with the class.
  5. Present the site and explain design choices.
