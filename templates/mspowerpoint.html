Unit 5: Presentations

Days 36–40 · Learn to design and deliver engaging presentations using PowerPoint or Impress.

Learning Objective: By the end of this unit you will be able to build a slide deck with text, images, and animations, and deliver it confidently as part of a group presentation.
1. Introduction to Microsoft PowerPoint/LibreOffice Impress

Presentation software is used to create slide decks that combine text, images, and multimedia to support a spoken talk.

  • Slide - a single screen in the presentation
  • Slide Layout - a template for arranging content on a slide
  • Slide Show mode - full-screen presentation view
2. Creating and Organizing Slides
  • Add new slides using the "New Slide" button
  • Choose layouts for title slides, content slides, and image slides
  • Reorder slides using the slide panel or drag-and-drop
  • Group related slides into clear sections
3. Adding Text, Images, and Graphics
  • Click into text placeholders to add titles and bullet points
  • Insert → Pictures to add images
  • Insert → Shapes/Icons for visual emphasis
  • Keep text concise - slides support the speaker, not replace them
4. Animations and Transitions
FeaturePurpose
AnimationControls how elements appear on a single slide
TransitionControls how one slide changes to the next

Use animations and transitions sparingly to avoid distracting the audience.

5. Presentation Skills and Group Presentation Project
  • Maintain eye contact and speak clearly
  • Practice timing so each slide gets appropriate attention
  • Use the slide as a visual aid, not a script to read word-for-word
  1. In groups, choose a topic learned earlier in the course.
  2. Create a 5-7 slide deck with a title slide, content slides, and a summary slide.
  3. Add at least one image and one animation.
  4. Assign speaking parts and rehearse as a group.
  5. Present to the class and answer questions.
Quick Quiz
  1. What is the difference between an animation and a transition?
  2. Why should slide text be kept concise?
  3. Name one way to reorder slides.
