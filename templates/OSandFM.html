Unit 2: Operating Systems & File Management

Days 11–15 · Learn how operating systems work and how to manage files and folders confidently.

Learning Objective: By the end of this unit you will understand what an operating system does, navigate a desktop environment, and confidently create, organize, and manage files and folders.
1. Introduction to Operating Systems

An operating system (OS) is the main software that manages a computer's hardware and software resources, acting as a bridge between the user and the machine.

  • Manages memory, storage, and processing tasks
  • Runs applications and provides a user interface
  • Handles input and output devices

2. Desktop, Taskbar, Icons, and Start Menu

The desktop is the main screen you see after logging in. It contains icons, a background, and a taskbar for quick access to programs.

  • Desktop - the main workspace with icons and shortcuts
  • Taskbar - shows open apps and the system clock
  • Icons - small pictures representing files, folders, or programs
  • Start Menu - central place to open programs and settings

4. Creating, Saving, and Organizing Files
  • Right-click on the desktop or in a folder to create a new file or folder
  • Use "Save As" to choose a file name, type, and location
  • Group related files into clearly named folders
  • Use logical naming conventions, e.g. "Project_Report_v1.docx"
5. Copying, Moving, Renaming, and Deleting Files
  • Copy - Ctrl+C, then Ctrl+V to paste a duplicate
  • Move - Ctrl+X (cut), then Ctrl+V in the new location, or drag-and-drop
  • Rename - right-click → Rename, or press F2
  • Delete - select the file and press Delete (moves to Recycle Bin/Trash)
6. Practical File Management Activities
  1. Create a folder called "My Projects" on the desktop.
  2. Inside it, create three sub-folders: Documents, Images, and Notes.
  3. Create a text file and save it inside Documents.
  4. Copy that file into Notes and rename the copy.
  5. Delete the original file and confirm it moved to the Recycle Bin.
