Computer Fundamentals

Learn the fundamentals of computers from the ground up.

Learning Objective: By the end of this lesson you will understand what a computer is, its history, components, operating principles, applications, advantages and limitations.
1. Definition of a Computer

A computer is an electronic device that accepts data (input), processes it according to a set of instructions, stores it, and produces meaningful information (output).

  • Input
  • Processing
  • Storage
  • Output
2. Origin & History

The word computer originally referred to a person who performed calculations manually.

Modern electronic computers evolved during the 1940s.

GenerationTechnologyYears
FirstVacuum Tubes1940-1956
SecondTransistors1956-1963
ThirdIntegrated Circuits1964-1971
FourthMicroprocessors1971-Present
FifthArtificial IntelligencePresent & Future
3. Characteristics
  • High Speed
  • Accuracy
  • Large Storage
  • Automation
  • Reliability
  • Versatility
  • Diligence (doesn't get tired)
4. Basic Components

Input Unit

Accepts data using keyboard, mouse, scanner, microphone, webcam etc.

CPU (Central Processing Unit)

The brain of the computer.

  • ALU - Arithmetic & Logical calculations
  • Control Unit - Controls all operations
  • Registers - High-speed temporary storage

Memory

  • RAM - Temporary memory
  • ROM - Permanent memory
  • Cache - Very fast memory

Output Unit

Monitor, Printer, Speakers and Projector display results.

5. Hardware

Hardware refers to the physical components that can be touched.

Examples
  • Keyboard
  • Mouse
  • Monitor
  • CPU Cabinet
  • Printer
Advantages
  • Upgradeable
  • Replaceable
  • Durable
Disadvantages
  • Physical damage
  • Needs maintenance
6. Software

Software is a collection of programs that tells the hardware what to do.

  • System Software (Windows, Linux)
  • Application Software (MS Word, Chrome, VLC)
